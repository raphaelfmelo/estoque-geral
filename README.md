# Estoque Prático

Sistema de gerenciamento de estoque desenvolvido como projeto de estudo.

## Tecnologias

- Python
- SQLite
- Streamlit

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Atualização de produtos
- Exclusão de produtos
- Entrada de estoque
- Saída de estoque
- Validação de estoque disponível

## Em desenvolvimento

- Histórico de movimentações
- Dashboard
- Alertas de estoque baixo
- Interface com Streamlit
